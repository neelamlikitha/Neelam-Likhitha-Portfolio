# Neelam Likhitha Portfolio

Welcome to my personal portfolio website! This site showcases my projects, skills, and background as a B.Tech graduate and aspiring software engineer.

## About

This portfolio is built with HTML, CSS, and a small amount of vanilla JavaScript:
- Home page with an introduction, social profiles, and featured projects
- About page with education, technical interests, and career objective
- Skills page grouped by technical area
- Projects page with project details and repository links
- Contact page with a validated email-draft form

## How to View

Open `index.html` in a browser to explore the portfolio. The contact form opens a prefilled draft in your email app; it does not submit or store messages on a server.

## Local profile photo preview

Open `about.html?owner=1` to show the profile-photo picker. Selected images are stored only in this browser's local storage. This is a local preview convenience, not authentication or a secure admin feature; do not rely on it to protect a public site.
